# codevid — 用代码画视频画面

把文章/脚本做成短视频，**画面逐帧用 PIL 绘制**，不调任何生图/视频模型。
配套文章：[做一个视频，不需要视频模型](https://www.tommickey.cn/essays/make-a-video-without-a-video-model/)

## 为什么不用生图

讲知识的视频，画面上真正出现的是柱子、流程、方框箭头、从零涨到五十的数字——
**这些本来就是算出来的**。交给生图模型它得猜「十六倍看起来像什么」，交给代码就是 `1` 和 `1/16`。

更要紧的是：**「画面和旁白对不上」这个失败模式从构造上消失了**。
旁白说差十六倍，柱高就来自同一个常量，不可能不一致。

代价要说清楚：**一次性更贵**（写场景的代码量远超写提示词），划算在第二次——
渲染层写完不动，下个片子只换 `*_scenes.py`。

## 用法

```
lib.py              渲染层：画布 / 配色 / 缓动 / 文本与图元。2× 超采样 + LANCZOS 抗锯齿
<topic>_scenes.py   每镜一个函数 fn(canvas, t)，t 是本镜进度 0–1
<topic>_narr.json   旁白分段，一段对一镜
render_<topic>.py   TTS → 排字幕 → 并发渲帧 → ffmpeg 合成
```

配色取自站点 `global.css` 的 `@theme` token，两边一致。

## 已踩过的坑（都写在对应代码的注释里）

- 🔴 `-shortest` 配 `-c:a copy` **静默吃掉尾部帧**（实测丢 62 帧）。音画差几毫秒根本不用它。
- 🔴 mp3 容器时长比解码样本长约 50ms，`apad=pad_dur=` 会每镜短一点，累计漂字幕。
  用 `apad`（补到无限长）+ `-t` 精确切。
- 🔴 字幕默认 `PlayResY: 288`，写 `FontSize=19` 实际渲成 84 像素。转 ASS 写死 720×1280。
  奶白底上**白字看不清**，要深墨字 + 奶白描边。
- 🔴 画连线要**先画线再画框**（框是 BG 填充的能盖住线），否则线压在文字上。
- 🔴 别用插值去「画」对勾之类的折线：两段线端点各自缩放会接不上，中途渲成竖杠。
  固定形状 + 纯淡入。
- ⚠️ 安全区：画面内容不过 y=1010（字幕烧在 ~1080）。
- ⚠️ cairosvg 也能画，但它的文本走 cairo toy API、字重和字体回退不可控，所以用 PIL。
